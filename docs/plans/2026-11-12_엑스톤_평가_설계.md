# 평가 설계 — 정답표 2종과 Liner 한국어 스모크 테스트 (2026-11-12)

관련: `docs/plans/2026-11-12_엑스톤_BRD_PRD_초안.md` 2절 「대표 성공 지표」(토론 합의 D5). 이 문서의 정답표와 합격 기준은 **구현 전에 고정**했다. 결과에 맞춰 바꾸지 않는다 — 바꿔야 하면 버전을 올리고 이유를 이 문서에 적는다.

## 1. 대표 지표 1 — 누락 탐지

| 항목 | 내용 |
|---|---|
| 가설 | 에이전트는 요청 메모에 심은 결함 10개 중 8개 이상을 질문·경고로 드러내고, 같은 메모를 한 번에 "PRD 써줘"로 호출한 결과보다 많이 드러낸다 |
| 기준선 | 한 번 호출("이 요청으로 PRD 써줘") 결과에 같은 채점 규칙을 적용한 탐지 수 — 키 발급 후 첫 측정 |
| 판정 기준 | 3회 반복의 최솟값 ≥ 8 이면 채택. 기준선과 같거나 적으면 "구별되는 가치" 주장은 기각 |
| 측정 방법 | 입력 `examples/flower-subscription/request_memo.md`, 정답 `eval/golden/seeded_defects.json`(충돌 3·빠진 예외 4·완료 기준 없음 3). 결함마다 `match_any` 단어 묶음 중 하나가 출력에 모두 나오면 탐지. 규칙이 애매한 경우는 사람이 판정하고 그 사실을 적는다 |

## 2. 대표 지표 2 — 변경 영향 재현율

| 항목 | 내용 |
|---|---|
| 가설 | 변경 발화 20건에서 에이전트가 대상 요구사항을 맞히고, 영향받는 REQ·SCR·TC 를 90% 이상 찾는다 |
| 기준선 | 구현 전이라 측정값 없음(0). 비교 대상은 정답표 자체 |
| 판정 기준 | 영향 재현율 ≥ 0.90(3회 반복 최솟값)이면 채택. 대상 적중률도 함께 적는다. 11-22 컷라인에서 3회 연속 미달이면 영상에서 빼고 로드맵으로 |
| 측정 방법 | 원본 `examples/flower-subscription/requirements_fixture.json`(REQ 11·SCR 5·TC 15), 정답 `eval/golden/change_cases.json`(20건, 대상 11종). 영향 규칙: 대상 REQ + depends_on 으로 전이적으로 기대는 REQ + 그 REQ 들의 SCR·TC |

- 영향 목록을 ID 링크로 결정적으로 계산하면, 이 지표가 실제로 재는 것은 **발화 → 대상 REQ 매핑**과 **링크 생성의 정확도**다. README 에 이렇게 밝힌다(오너 지적)

### 정답표 자체의 검증
- `eval/validate_golden.sh` — 원본 링크 무결성, 20건 기대 영향 = 규칙 재계산, 10개 결함 인용문이 메모에 그대로 있는지
- 2026-11-12 결과: `golden sets: OK`(exit 0). 반증 시험: 기대 테스트 삭제·메모에 없는 인용문·없는 REQ 의존·19건으로 줄이기 — **4건 모두 exit 1 로 잡음**

## 3. Liner 한국어 스모크 테스트 (본체 LLM 선택)

| 항목 | 내용 |
|---|---|
| 가설 | liner-mark-1.3 이 한국어 요청 메모에서 형식·원문 충실·쉬운 말·속도 기준을 모두 통과한다 |
| 기준선 | 측정값 없음 — 공식 한국어 지원 진술 0건(대회조사 3절) |
| 판정 기준 | C1 10회 호출 모두 JSON 형식 정상 · C2 원문 인용 그대로 비율 ≥ 90% · C3 질문 카드 5개 모두 금지어 0개 + 선택지 2~4개 · C4 호출 시간 중앙값 ≤ 15초. liner-mark-1.3 이 넷 다 통과하면 기본값, 아니면 claude → gpt → gemini 라우터 순으로 첫 통과 모델. 전부 실패면 보고하고 고르지 않는다 |
| 측정 방법 | `eval/smoke/liner_korean_smoke.sh` — 모델별 메모 5개(꽃집 + `eval/smoke/memos/` 4개, 모두 가상) × 과제 2개(요구사항 후보 추출, 요청자용 질문 카드), `response_format: json_schema`. 결과는 `eval/results/smoke-*.jsonl` |

- 채점 로직 검증(2026-11-12): 가짜 응답으로 시험 — 원문 그대로·쉬운 말 모델은 PASS, 원문 변형·전문 용어 모델은 C2·C3 FAIL. 이 과정에서 요약 jq 식의 문법 오류 1건을 찾아 고쳤다
- 예상 비용: 4모델 × 10호출 = 40호출, 짧은 입력이라 $1 미만(추정, 실측 아님)

## 4. 한계

- 테스트 규칙의 「AI 기능 4번째 층」은 대표 입력 20건 이상을 요구한다. 지표 1은 메모 1건(결함 10개)이라 **시연용 지표이지 회귀 평가 세트로는 부족**하다 — 회귀용 메모를 늘리는 것은 별도 작업
- 정답표는 작성자 1인이 만들었다. 결함 「빨리」의 기준 등은 판정 단어 선택에 작성자 판단이 들어갔다
- 스모크 테스트의 금지어 목록과 15초 기준은 작성자가 정한 값이다
